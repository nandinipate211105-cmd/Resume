# Resume
A responsive personal resume website built using **HTML, CSS** to showcase my education, technical skills, projects, achievements, certifications, and contact information in a clean and professional format.

## Features

* Responsive and modern UI
* About Me section
* Education details
* Technical skills
* Projects showcase
* Achievements & Certifications
* Contact information
* Smooth navigation

## Tech Stack

* HTML5
* CSS3

## Purpose

This project serves as my digital portfolio, allowing recruiters and visitors to learn about my background, skills, and work through an interactive web interface.
